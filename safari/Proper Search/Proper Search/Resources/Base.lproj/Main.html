Proper Search

Find text beyond what’s visible. Search collapsed sections and hidden content already loaded on a page.

You can turn on Proper Search’s extension in Safari Extensions preferences.

Proper Search’s extension is currently on. You can turn it off in Safari Extensions preferences.

Proper Search’s extension is currently off. You can turn it on in Safari Extensions preferences.

First-time setup
  1. In Safari Settings → Advanced, enable Show features for web developers.
  2. In the Developer tab, enable Allow unsigned extensions for this local build.
  3. In Extensions, turn on Proper Search.

Click the magnifier in Safari’s toolbar on any website, allow access if prompted, then type your search.
